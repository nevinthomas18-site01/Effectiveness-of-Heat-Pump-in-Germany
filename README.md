# Heat Pump Integration Atlas — Bavaria

A research portfolio showing how heat pumps can integrate with shallow geothermal energy, managed rainwater, combined heat and power (CHP), thermal storage, and recoverable waste-heat streams.

The website includes:

- a rainwater-assisted geothermal basket concept;
- retrofit guidance for existing residential buildings;
- a CHP and heat-pump integration block diagram;
- waste-heat recovery sources, priorities, and feasibility requirements;
- shallow-geothermal versus fracking guidance;
- risks, site-screening questions, and authoritative sources.
